# CampusEats

CampusEats is a campus food ordering and management system developed for
CS 543 Web Services.

The system allows campus users to discover food vendors, view menus,
place food orders, make payments, and track orders.

## CS 543 Assignment 1

This repository contains the work for Assignment 1:

- HTTP request and response experiments using curl
- Browser Network panel analysis
- CampusEats system brief
- Project documentation
